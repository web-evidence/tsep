# Migration draft.20 → draft.21

## Français

TS34 et TS35 gagnent cinq règles atomiques, sans changement d'identifiants des
44 contrôles. Interpréteur 21, adaptateur 22, rejeu 3. Les treize règles exécutables
antérieures gardent leurs décisions ; les anciens rapports se rejouent avec leur
archive exacte. Aucun ancien dossier ou tag n'est remplacé.

Les nouveaux rapports sélectionnent explicitement TS34-A01/A02/A03 ou TS35-A01/A02,
avec les entrées décrites dans [le contrat performance](performance-evidence.md).
Une ancienne déclaration C sans ces observations ne devient pas C sous draft.21.
Reprendre le plan, fournir les originaux et les décisions réellement disponibles,
puis produire un autre dossier. Ne pas inventer de revue ni de données terrain.

Le contrôle documente les performances : C peut accompagner une classe Poor.
La séparation doit rester visible dans les rapports, EARL et résumés. Le rejeu
recalcule l'interprétation des pièces ; il ne mesure pas le site à nouveau.

## English

Five atomic rules are added to TS34/TS35, preserving all 44 control IDs. Interpreter
21, adapter 22, replay 3. Earlier thirteen executable rules keep their decisions;
old bundles replay with their exact archives, not replacement tools or tags.

Explicitly select TS34-A01/A02/A03 or TS35-A01/A02 and supply inputs under the
[performance contract](performance-evidence.md). An earlier C without these atomic
observations does not establish C under draft.21. Prepare a new plan and bundle
with originals and genuinely supplied decisions; do not invent reviews/field data.

C describes documentation and may accompany Poor metric quality. Keep this
distinction visible in reports, EARL and summaries. Replay is interpretation of
retained evidence, not a new site measurement.
