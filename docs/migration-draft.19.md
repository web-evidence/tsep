# Migration draft.19 — HTTP canonical context / Contexte canonical HTTP

## Français

Interpréteur 19, adaptateur 20, rejeu 3 ; rapport 2, treize règles et 44 identités
conservées. Le nouveau choix préalable `http-link-context-v1` étend TS10-A01/A02.
Son contrat FR/EN entre dans les empreintes normatives. Les versions de règles
identifient cette édition ; provenance et anciennes publications restent intactes.

Les 640 cas historiques, leurs entrées et résultats ne sont pas migrés. Leurs deux
limites rel/anchor restent visibles sous l'ancien lecteur ; 61 cas synthétiques
distincts exercent le nouveau choix. Une sélection inconnue ne choisit aucun repli.
Une incompatibilité HTTP certaine peut maintenant survivre à une source HTML non
prise en charge lorsqu'on a explicitement choisi ce profil. Les autres méthodes
et les obligations de revue restent inchangées.

Pour une nouvelle collecte, choisir le profil avant les captures. Pour relire des
octets anciens, conserver plan et dossier originaux et produire une **relecture
rétrospective distincte** expliquant le choix postérieur. Recalculer les jugements
humains seulement avec une nouvelle revue réellement fournie ; ne pas réparer
automatiquement leurs empreintes. Rejouer les anciens dossiers avec leurs outils
archivés. Un dossier créé par adaptateur20 conserve ses diagnostics HTTP et ses
sources pour le rejeu exact. Aucun nouveau résultat Edikka ou Google n'est revendiqué.
