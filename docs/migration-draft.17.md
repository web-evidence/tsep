# Migration draft.17 — liens source / source links

## Français

Interpréteur 17, adaptateur 18, rejeu 2 ; format de rapport 2, treize règles et
44 identités/provenances conservées. Seule TS10-A04 reçoit le profil source
préalable html-tree-links-v1, décrit dans [son contrat](source-link-policy.md),
désormais inclus dans les empreintes normatives. La version des règles et du
schéma identifie cette édition distincte ; aucun tag/paquet ancien n'est remplacé.

Sans champ source_reader dans intent.canonical.links, les 543 cas antérieurs
gardent exactement leurs entrées et résultats calculés. Le champ canonical.source_reader
de draft.16 n'active pas A04. Node24 reste une dépendance facultative à fournir pour
ce profil ; aucune installation automatique ou relecture favorable de substitution.

Déclarer le profil et les URL de famille déjà sérialisées avant de nouvelles captures.
Ne pas modifier une intention historique pour la présenter comme préalable. Une
relecture de corps conservés s'intitule rétrospective. Rejouer les anciens dossiers
avec leurs outils archivés. A01/A02, sitemaps, robots et DOM gardent leurs méthodes.

Les sorties de la nouvelle lecture portent la convergence limitée de la famille et
les comptes, y compris zéro, jusque motif TS10 et scope_notes du gate. Les anciens
rapports sans ce profil n'acquièrent pas cette annotation. A04 ne devient pas une
obligation de présence de lien ; états rendus et revues nécessaires restent exigés.

## English

control identities/provenance. Only A04 gains the prior source profile; its bilingual
contract enters normative fingerprints. Absent selection preserves all543 historical
inputs and computed results exactly. Draft.16's canonical.source_reader does not
select A04. Optional Node24 must be supplied separately, with no fallback/install.

Select the profile and already serialized family URLs before new captures. Do not
retrofit intent, replace historical packages/tags or claim a retrospective reading
was prospective. Replay historical bundles with original tools. New profile reasons
and gate scope_notes expose limited convergence/counts, including zero. No link
presence requirement is added; A01/A02, other controls and rendered/review requirements
remain unchanged. This is a candidate protocol, not a recognized standard.
