# Migration draft.21 → draft.22

## Français

TS42 gagne trois règles ; TS01–TS44 gardent leurs identifiants et titres. Les
18 règles antérieures et leurs 857 cas bruts sont conservés. Interpréteur 22,
adaptateur 23, rapport HTML 6, rejeu 3. Les versions de règles des contrôles
atomiques désignent la nouvelle candidate ; les anciens tags et dossiers restent
liés à leurs sources et outils exacts. Aucun remplacement ou migration silencieuse.

Sélectionner explicitement TS42-A01/A02/A03 pour un nouveau dossier. Fournir le
plan, les sources datées, leurs revues, la décision réelle du responsable et la
capture selon [le contrat](agent-usage-policy.md). Une ancienne déclaration C
sur TS42 ne remplace pas ces observations. Ne pas antidater le plan ou inventer
une autorisation ; un dossier incomplet reste NT. Un désaccord établi reste NC
malgré d'autres inconnues. Les exemples synthétiques ne deviennent pas un audit.

TS43/TS44 demeurent à développer. Le nouveau contrôle n'établit pas de visite,
respect des politiques par les opérateurs, citation, classement ou certification.

## English

Three atomic rules are added to TS42; all TS01–TS44 IDs/titles stay fixed. The
18 earlier rules and their 857 raw cases are retained. Interpreter 22, adapter 23,
HTML report 6, replay 3. Atomic control rule versions reference this new candidate;
previous bundles/tags retain exact sources and tools. No replacement or silent migration.

Explicitly select TS42-A01/A02/A03 for a new bundle with a prior plan, dated sources,
supplied reviews, actual owner decision and policy capture under the new contract.
Earlier C declarations do not replace these observations. Do not backdate plans or
invent approval. Missing evidence stays NT; an evidenced contradiction remains NC
alongside other unknowns. Synthetic exercises are not a real site assessment.

TS43/TS44 still require development. No actual visit, provider compliance, citation,
ranking or certification is established by TS42.
